7️⃣ OPTIONS DE CRÉATION DE DONNÉES
=============================================================
☐ DÉCOCHER : "Tronquer la table avant d'insérer"

☐ DÉCOCHER : "Instructions INSERT IGNORE"

Fonction : "INSERT"

Syntaxe : Sélectionner "insérer des lignes multiples avec chaque instruction INSERT"
   ☑️ Par exemple : INSERT INTO tbl_name VALUES (1,2,3), (4,5,6), (7,8,9)

⚙️ Taille maximale de la requête générée : 10000
   (Réduire de 50000 à 10000 pour éviter les timeouts)

=============================================================
8️⃣ TABLES À IGNORER (Optionnel mais recommandé)
=============================================================
Si vous avez l'option "Ignorer les tables", ignorez ces tables temporaires :

❌ telescope_entries
❌ telescope_entries_tags
❌ telescope_monitoring
❌ cache
❌ cache_locks
❌ sessions
❌ jobs
❌ job_batches
❌ failed_jobs

Ces tables se régénèrent automatiquement et peuvent être TRÈS volumineuses.


=============================================================
9️⃣ LANCER L'EXPORT
=============================================================
Cliquez sur le bouton "Exporter" en bas de page.

✅ Vous obtiendrez un fichier ZIP contenant plusieurs fichiers .sql.gz
✅ Chaque table sera dans un fichier séparé
✅ L'export sera beaucoup plus rapide (pas de timeout global)


=============================================================
📥 RÉSULTAT ATTENDU
=============================================================
Nom du fichier : c0admin.sql.zip
Contenu : Plusieurs fichiers .sql.gz (un par table)
Taille : Environ 70-90% plus petit que l'original grâce à la compression


=============================================================
🔄 RESTAURATION
=============================================================
Pour restaurer le backup :

1. Décompressez le fichier ZIP
2. Décompressez chaque .sql.gz
3. Importez chaque .sql dans phpMyAdmin OU via ligne de commande :

   for file in *.sql; do
       mysql -u root -p c0admin < "$file"
   done
